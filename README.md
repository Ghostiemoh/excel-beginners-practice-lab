# Excel Beginners Practice Lab 📊

A set of **12 interactive, self-correcting Excel practice workbooks** designed for MS Office beginners to master essential formulas, data analysis, and spreadsheet design. 

This repository contains **12 individual Excel workbooks** covering core concepts. Each workbook features a **cover instruction sheet**, an **expanded 80-row dataset** for hands-on practice, and a **live validation system** that gives students instant feedback on their formulas.

📂 **Download the Entire Lab**: [MS Office Beginners Practice Lab](https://github.com/Ghostiemoh/excel-beginners-practice-lab)

---

## 🏗️ Repository Structure

Each exercise workbook is structured with:
1. **`Instructions` (Cover Tab)**: Outlines the learning objective, key Excel concepts, step-by-step instructions, and displays a **Live Validation Status** (`[ Pending ]` / `✅ Correct` / `❌ Try Again`).
2. **`Exercise` (Practice Tab)**: Contains a formula hint box, pre-set raw data, and **80 practice records** where the student enters their formulas in designated light-grey cells.
3. **`Reference_Answers` (Hidden Tab)**: Pre-calculated correct answers that drive the live validation checking.

## 🎨 Visual Design & Theme
- **Theme**: Premium **Slate & Teal** brand system.
  - Headers: Dark Slate Blue (`RGB: 30, 41, 59`) with bold white text.
  - Title Blocks: Teal Accent (`RGB: 4, 138, 81`) with bold white text.
  - Alternating Rows: Light Grey (`RGB: 248, 250, 252`) for readability.
- **Input Formatting**: Light-grey practice cells with blue text font (financial modeling standard) that remain blank until student formulas are written.

## 🚀 How to Use These Exercises
1. Clone or download this repository.
2. Open any of the `.xlsx` files in **Microsoft Excel**, **Google Sheets**, or any compatible spreadsheet software.
3. Read the learning objectives on the **`Instructions`** sheet.
4. Switch to the **`Exercise`** tab, inspect the raw data, and write your formulas in the light-grey cells.
5. Watch the cover sheet status change to `✅ Correct` once all 80 rows are completed correctly!
